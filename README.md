# Трекер полезных привычек (Habits Tracker)

Проект представляет собой сервис для отслеживания и управления полезными привычками, основанный на принципах из книги Джеймса Клира "Атомные привычки".

Сервис позволяет пользователям создавать привычки, устанавливать напоминания и получать вознаграждения за их выполнение. Интеграция с Telegram обеспечивает своевременную отправку уведомлений. Проект полностью контейнеризирован с помощью Docker и настроен на автоматическое развертывание через CI/CD на GitHub Actions.

---

## 🚀 Ключевые возможности

*   **Создание привычек:** Пользователи могут создавать "полезные" и "приятные" привычки, следуя шаблону: `я буду [ДЕЙСТВИЕ] в [ВРЕМЯ] в [МЕСТО]`.
*   **Система вознаграждений:** За выполнение полезной привычки можно получить либо текстовое вознаграждение, либо выполнить связанную с ней "приятную" привычку.
*   **Гибкая настройка:** Возможность указать место, время, периодичность (в днях) и время на выполнение привычки.
*   **Публичные привычки:** Пользователи могут делать свои привычки публичными, чтобы другие могли брать их в качестве примера.
*   **Умные валидаторы:**
    *   Нельзя одновременно указать вознаграждение и связанную приятную привычку.
    *   Время на выполнение привычки ограничено 120 секундами.
    *   В связанные привычки можно добавлять только те, что имеют признак "приятной".
    *   У приятной привычки не может быть своего вознаграждения или связанной привычки.
    *   Периодичность выполнения не может быть реже, чем раз в 7 дней.
*   **Интеграция с Telegram:** Автоматическая отправка напоминаний о выполнении привычек в указанное время.
*   **Безопасность и права доступа:** Пользователи имеют полный доступ (CRUD) только к своим привычкам и могут просматривать список публичных привычек других пользователей.
*   **Документация API:** Автоматически генерируемая документация для всех эндпоинтов.


##  API Эндпоинты

#### Пользователи (Users)
*   `POST /users/register/` - Регистрация нового пользователя.
*   `POST /users/token/` - Получение JWT токена (авторизация).
*   `POST /users/token/refresh/` - Обновление JWT токена.

#### Привычки (Habits)
*   `GET /habits/` - Получение списка своих привычек с пагинацией (по 5 на страницу).
*   `GET /habits/public/` - Получение списка публичных привычек.
*   `POST /habits/` - Создание новой привычки.
*   `GET /habits/{id}/` - Просмотр конкретной привычки.
*   `PUT /habits/{id}/` - Полное обновление привычки.
*   `PATCH /habits/{id}/` - Частичное обновление привычки.
*   `DELETE /habits/{id}/` - Удаление привычки.
